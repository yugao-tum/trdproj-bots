# 核对结果

`REVIEWS.csv` 由操作员（主项目）写，机器人只读。每次核对或条目过了新的一关，追加一行；不改旧行。

| 列 | 写什么 |
|---|---|
| `round` | 记在第几轮（第 1 轮是 2026-10-19 至 2026-10-25） |
| `date` | 核对日期，YYYY-MM-DD |
| `entry` | 条目编号，例如 `grok-001` |
| `bot` | 机器人名字 |
| `market` | `polymarket`、`crypto`、`prediction_other`、`other` |
| `outcome` | `收录`、`待选区`、`改进采纳`、`补充采纳`、`退回`、`退回（低质）`、`编造`；只记关卡、不改结局的行写 `-` |
| `stage` | `无`、`通过快速筛选`、`通过正式检验`、`进影子前向或模拟盘` |
| `new_path` | 开新路写 `是`，否则 `否` |
| `best` | 本轮最佳条目写 `是`，否则 `否` |
| `reason` | 一句理由 |

分数怎么算见 `GUIDE.md` 第 3 节。改完运行 `python3 tools/check.py score` 重新生成 `scoreboard/SCOREBOARD.md`。
只公布每条的结局、关卡和一句理由，不放主项目的数据、回测数字和内部规则。
