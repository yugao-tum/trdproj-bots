> 作者：Muse 直属 agent（muse-agent-10）｜ 补位第 2 批

## 一句话

先用"已实现盈亏高、结算笔数多、回撤小、利润不靠单注"四条给 Polymarket 全部钱包打分，只跟随高分钱包的新开仓（延迟入场、持有到结算），赚知情资金先下单、价格慢慢跟上来的那段信息差。

## 钱从哪里来

付钱的是定价慢的散户对手盘。事件市场里有真做过功课的人——2024 年大选的法国交易员 Théo 用约 3000 万美元在 Polymarket 建仓，最终获利约 4800 万美元（NY Post 已读，引平台/WSJ；四钱包与金额可对上）。其"自费邻居模型民调"的说法见 ai-trading-ranked 二手汇总（摘要），未独立核实。这类人的订单先到，价格随后才慢慢反映其信息。盲目跟单会跟到运气型钱包，所以先评分：只跟"多次结算验证过、赚钱不靠一注"的钱包，过滤掉一次性赌对的噪声。跟随者赚的是信息级联里价格未走完的那一段。

## 规则

- 信号（每周重算）：钱包满足 ①已结算交易 ≥30 笔 ②投入回报 ≥15% ③最大回撤 ≤25% ④单一注贡献利润 ≤50%，入选跟踪池（门槛参照 Whalidate 公开的默认评分，见出处）。
- 触发：跟踪池钱包在某市场新开仓 ≥5000 美元（或加仓至该量级），跟随者在信号后 1 小时内以市价同向建仓，单市场仓位 ≤总资金 5%。
- 持有到结算，不止损（事件市场中途波动大）；钱包一周内反向平仓过半则提前退出。
- 结算规则要点：Polymarket 二元市场按市场页规则由 UMA 乐观预言机裁定结果，胜方份额按 1 美元赎回、负方归零；结算数据源以各市场规则原文为准。

## 证据

- Théo 案例：4 个钱包（Théo4、Fredi9999、PrincessCaro、Michie）合计约 3000 万美元押特朗普获胜，获利约 4800 万美元（NY Post 已读，引平台/WSJ；利润数字为平台与媒体口径，未独立复核）。其"自费邻居模型民调"见 ai-trading-ranked 二手汇总（摘要，未独立核实）；四钱包与金额本身支持"头部钱包携带大额方向性信息"这一较弱表述。
- 工具侧佐证：Polycopy 称跟踪 50 万+ 钱包并按"已验证链上盈亏"排名、另设 Copy Score 区分真实 edge 与单注运气；Whalidate 的 WhaleFinder 用回报/结算笔数/回撤/单注集中度给钱包打分，2026-09-30 时 1346 个完整评分钱包中 166 个通过其默认门槛（均为来源自报，未核实）。
- 反面证据（须诚实记录）：有二手评论（原链接已跳转站点首页，无法核验）指出鲸鱼流会制造"信息级联"——价格反映的不再是群体判断而是单个大户信念，跟随者等于接级联的后段；且鲸鱼建仓本身会推价，跟随入场价系统性差于鲸鱼成本。
- 第三方 review 转述的负面结果（2026-10-20 补录，原“工具方自带”表述有误）：polbots.com/bot/whalidate（页面未标发布日期）称，把通过默认门槛的 166 个钱包按同一套三条入场规则跟随，120 天（至 2026-09-30）合计约打平、收益 **−1.9%**，并写“60 天表现最好的钱包，不一定在下个 60 天最好”。但 Whalidate 自己的方法页（2026-10-18 更新）对同一 166 钱包、同一 120 天写的是“close to break-even, about +$1.50 per $100 copy”（≈+1.5%，且不含滑移和手续费）；两者冲突，均未独立复现。反面对照保留：无论取 −1.9% 还是 +1.5%，都说明“过门槛”不等于可跟随——本条目的四维评分只是入选池，跟随前仍需二次筛选与仓位控制；两周检验的第一关就是复现并拆解这一数字（是哪些钱包拖累、评分加严后是否转正）。

## 数据

Polymarket Data API：排行榜、任意钱包的持仓、成交历史、盈亏，全部公开、免密钥（已由开源项目 n8n-nodes-polymarket-tools 文档核实，其 Data 资源含 Get Leaderboard / Get Wallet Positions / Get Wallet Trades / Get Market Holders）；限流约 1000 请求/10 秒（成交 200/10 秒），1–5 分钟轮询足够。Data API 单市场仅约最近 2 万笔（GUIDE §8），钱包全历史不保证；历史检验需按可见窗口取样并在条目里记录起点。官方文档：v1 于 2026-10-24 停用，届时改用 v2（字段 proxy_wallet、cursor 分页）。

## 两周内怎么检验

用 Data API 拉过去 3 个月内已结算的二元市场全量成交：①按信号规则回算每周钱包评分（只用当时点之前的数据，防前视）；②对每个高分钱包-市场首次开仓事件，记录鲸鱼成交价、+1 小时市价、结算结果；③统计跟随策略毛收益与扣往返成本（Polymarket 费用按 GUIDE §8 口径）后净收益、胜率；独立事件按事件计（同一事件的多个市场只算一个），目标 ≥30 个（鲸鱼活跃市场一周内可凑齐）；失败标准：净收益中位数 ≤0，或胜率 ≤55%，或合格事件 <30 个（样本不足即不达标）。

## 成本与容量

跟随延迟 1 小时的价格滑移是主要成本（鲸鱼大单会推价，量级未实测，暂标不确定）；Polymarket 交易费低，主要磨损在买卖价差与滑移。容量：只做成交量靠前的市场、单注 ≤5000 美元时对价格影响有限，5000 USDT 本金可执行（每次跟随 100–250 美元）。Data API 免费用，工具成本为零。

## 风险

①信息级联反噬：鲸鱼判断错误时跟随者全额承担（Théo 在选前一天也有约 300 万美元浮亏，方向错即归零级亏损）；②评分过拟合：过去高分不保证未来，钱包可能换策略或就是运气未被 30 笔过滤干净；③鲸鱼故意布假单引诱跟随（链上全透明，聪明钱知道自己在被跟）；④结算争议/预言机异常风险与平台规则风险。

## 门槛自查
1. 机制说得清：满足。知情钱包（私有调研/信息优势）先下单，散户定价滞后，跟随者赚价格向真实概率收敛的差额；评分过滤掉运气型钱包。
2. 有免费数据能检验：满足。Polymarket Data API 公开免密钥，钱包成交/持仓/盈亏与市场结算结果全可拉，历史可回溯。
3. 小资金能做：满足。单次跟随 100–250 美元，5000 USDT 可分散到 20+ 个事件。
4. 不重复：满足。与 known/C-C1-whale-net（永续合约大户净持仓总量信号，无钱包身份、无评分）关键变量不同；与 C-C1-hl-copytrade（Hyperliquid 盲跟单）不同：本条是预测市场、评分筛选后跟随；与 dot-016 订单流不平衡（BTC 永续匿名订单流）不同：本条基于钱包身份与历史战绩；与本队 muse-911（GDELT 文本情绪）不同：本条是链上持仓数据。
5. 扣成本后粗算够用：不确定。跟随滑移（鲸鱼推价幅度）未实测，需两周检验给出数字，不硬编。
6. 两周内能检验：部分满足。历史回算一周内可完成，但须按事件去重（同一事件多市场只算一个）；去重后 ≥30 个独立事件是否可达未验证。
7. 出处可查：部分满足。Théo 案例与 Data API 能力有可访问出处；但 166/1,346 为 Whalidate 自报（本次已开方法页，未独立复算），−1.9% 仅见 polbots 第三方 review，且与 Whalidate 方法页的 +1.5% 冲突；钱包名单与评分不可公开复算。
