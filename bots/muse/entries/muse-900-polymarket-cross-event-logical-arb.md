## 一句话

当两个或多个不同 Polymarket 事件之间存在可证明的逻辑约束（A 发生则 B 必须发生、两者不能同时发生、若干事件恰好发生一个、C 等价于 A 且 B），而市场报价违反该约束时，买入被低估的一侧、卖出/买入互补侧，构造到期支付至少为 1、成本低于 1 的组合。

## 钱从哪里来

- **付款方是把每个事件单独定价的交易者**。预测市场按单个问题组织订单簿，参与者常按新闻叙事交易某一条腿，没有把“提名→当选”“初选胜出→全国胜出”“A 且 B→A”这类跨事件支付关系算进价格。多腿执行、语义核对、资金占用和结算不确定性让套利者稀少，价差因此可以短暂存在。
- **不是平台补贴**：本条赚的是报价不一致，不是返佣、奖励或做市补贴；平台费用和滑点是净成本的减项。
- **收益上限来自逻辑约束**：互斥 A/B 同时为真的概率为 0，因此 `P(A)+P(B)≤1`；A 蕴含 B 时 `P(A)≤P(B)`；分割关系 `ΣP(A_i)=1`；conjunction `P(C)≤P(A)` 且 `P(C)≤P(B)`。报价违反这些不等式时，反向组合的到期支付有下界。
- **为什么可能持续**：跨事件关系不在订单簿里，平台不会自动执行；识别关系需要读规则、对齐截止时间、处理同名/近名市场，且组合腿数越多、深度越差。论文样本中 25.4% 的检测窗口至少有一笔执行成交，说明机会并非全部瞬间消失，但也不是稳定现金流。

## 规则

### 只做可证明的跨事件关系

设 `z_i ∈ {0,1}` 为合约 i 的到期支付。只允许以下四类，且组合中的所有合约必须来自**不同 event**（同一 event 内的阈值阶梯归 `dot-007`，同一 event 的 NegRisk 完整集归 `dot-006`，跨场所归 `dot-005`，均不在本条重复）：

| 关系 | 约束 | 报价违反 | 纸面组合 |
|---|---|---|---|
| 互斥 A、B | `z_A + z_B ≤ 1` | `bid_A + bid_B > 1` | 买 NO_A + 买 NO_B（等价于卖两腿 YES） |
| 分割 A1…An | `Σ z_Ai = 1` | `Σ bid_Ai > 1` 或 `Σ ask_Ai < 1` | 全部买 NO（高价时）或全部买 YES（低价时） |
| 必要条件 A⇒B | `z_A ≤ z_B` | `bid_A > ask_B` | 买 NO_A + 买 YES_B |
| 合取 C=A∧B | `z_C ≤ z_A`、`z_C ≤ z_B` | `bid_C > ask_A` | 买 NO_C + 买 YES_A（或 B） |
| 合取 C=A∧B | 同上 | `ask_C < bid_A + bid_B − 1` | 买 YES_C + 买 NO_A + 买 NO_B |

- **互斥**：两腿最多一个支付 1；买两个 NO 的成本 `(1−bid_A)+(1−bid_B) < 1`，到期至少一个 NO 支付 1，若两者都未发生则两个 NO 都支付 1，因此支付 ≥1。
- **分割**：恰好一个支付 1；高价时买全部 NO，成本 `n−Σbid < n−1`，到期至少 `n−1`；低价时买全部 YES，成本 `Σask < 1`，到期恰好 1。
- **必要条件**：A 发生则 B 必须发生；买 NO_A + YES_B 的成本 `(1−bid_A)+ask_B < 1`，A 真时支付 1，A 假时 NO_A 支付 1，因此支付 ≥1。
- **合取**：C 真则 A、B 都真；`bid_C > ask_A` 时买 NO_C + YES_A，成本 `<1`，C 真时 YES_A 支付 1，C 假时 NO_C 支付 1；另一侧同理。
- **只做“支付有下界”的组合**，不把“价格会收敛”当套利。若关系本身有争议、结算源不同、截止时间不同，支付下界不成立，直接排除。
- **不猜价格方向**：所有组合在到期时支付至少 1，成本在成交时锁定；不是统计套利，不依赖对结果的预测。

### 关系抽取与审计

1. 先取每个市场/事件的规则原文、`endDate`、结算源、结果集合；只处理已命名、非 placeholder、`negRiskAugmented=false` 的完整结果集（若涉及 NegRisk）。
2. 第一层用确定性解析：日期、阈值、比分、候选人、党派、同一决议的 explicit 关系；第二层才用 LLM 从规则文本抽取候选关系，输出必须带原文片段和反例检查。
3. **每一条关系在纸面交易前人工审计 100%**；审计不通过的关系不进入组合。LLM 只做候选召回，不作为最终裁判。
4. 关系必须满足：A 真 ⇒ B 真（或互斥/分割）在所有可能结果下成立，而不是“历史上通常一起发生”。
5. 排除：同一 event 的不同阈值（`dot-007`）、同一 NegRisk 事件的完整集（`dot-006`）、仅靠标题相似匹配的跨场所对（`dot-005`）、结算日期/数据源不一致的对。

### 组合与执行

- 把候选关系写成约束系统 `F z ≤ g`，`z∈{0,1}^I`；对最多 5 条腿枚举组合，计算 `min_z (支付) − 成本`，只保留下界 > 0 的组合。
- 价格用可成交的 ask/bid，不用 mid；买 YES/NO 都按对应侧的 ask，卖 YES 用买 NO 表达，不假设能裸卖或瞬时借券。
- 组合腿按顺序下单，允许部分成交；任一条腿未成交时，已成交腿必须在二级市场退出或按最坏情况预留对冲成本，不能假设整篮原子成交。
- 单组合最多 5 条腿、单腿不超过总资金的 20%；单场所总未平仓 + 费用 + 退出缓冲 ≤2,500 USDT。
- 结算前不主动平仓；若市场提前出现更优报价，可平仓但必须把退出费用计入，不能把未实现价差当利润。

## 证据

- **来源自报，未核实**：论文《Combinatorial Arbitrage in Prediction Markets》（Hongjian Shi / Daojing Zhai，2026-10-17 版）称，2026-06-23 至 2026-08-03 从 Polymarket 的 1.9M 条逻辑关系、255,000+ 合约中检测到 491,827 个套利窗口，其中 125,095 个在回放中被执行（25.4% 的检测窗口至少有一笔执行）；结算样本累计 $2.50M 保证利润、$113.7M 累计资本，累计资本回报 2.2%（不是每笔）、峰值资本 $11.1M 时约 3.5%/周；首次执行 $1.10M。
- 同一论文：关系来源为 venue-asserted 34%、venue-derived 59%、semantic-inferred 7%；1 秒下单延迟仍保留 79% 的到期利润；854 个地址参与，top-10 占 78% 的执行窗口；semantic-inferred 的 29,097 个执行窗口中，持续 ≥0.3 秒的子样本中位持续 30.8 秒、62% 持续 ≥10 秒；venue-asserted 中位 2.9 秒，venue-derived 6.3 秒。
- 论文的语义层有 562,944 条关系（含 537,381 条 implication），说明“读规则找关系”不是手工个例；但论文没有把跨 event 与同一 event 内关系分开报告，**本条只取跨 event 子集，机会数会显著小于论文总数**，这是把论文证据外推到本条时最大的折扣。
- 论文的示例 `over 3.5 vs over 2.5` 是同一场比赛的阈值阶梯，属于 `dot-007` 的覆盖范围，不作为本条的新颖性证据；本条的新颖性是跨 event 的 implication/mutex/partition/conjunction 组合。
- 论文的数据不是公开历史 L2：作者自行采集 73.22B 条 messages 和 229.9M 条成交（arXiv v2；10-17 版 PDF 为 227M）；我们没有复现其数据，也没有独立回测。`backtest_count=0`，`observed_net_return=null`。
- 本条的正面证据仅限于“机制 + 论文的样本统计”，不是“我已在当前市场赚到钱”。当前 Gamma/CLOB 重取在 2026-10-20 超时，本文不引用未复核的实时价格。

## 数据

- **Gamma**：`https://gamma-api.polymarket.com/events?slug=...`、`/markets?slug=...`；免费免密钥；返回规则原文、outcomes、`negRisk`、`negRiskAugmented`、`endDate`、`feeSchedule`、tick、min size。用于建立事件/合约目录和规则文本。
- **CLOB**：`https://clob.polymarket.com/book?token_id=...`；免费免密钥；当前全深度盘口；历史 L2 无免费完整源，`/prices-history` 只有有限历史。
- **data-api**：`https://data-api.polymarket.com/trades?market=...`；免费免密钥；每个市场约最近 2 万笔公开成交；用于前向记录成交和结算后的支付核对。
- **缺失**：免费历史全深度 L2；跨 event 关系的标注集；每条关系的真实可执行深度；Polygon 结算/赎回 gas（若持有到结算）。这些缺失决定了两周检验只能前向记录，不能做完整历史回测。
- **记录频率**：每 30–60 秒抓一次所有候选事件的 top 20 档；关系审计与价格记录分开，先审计后交易，避免用未来信息挑关系。

## 两周内怎么检验

- **范围**：14 天内，每天扫描所有 active Polymarket 事件；优先政治（提名/当选/退选/党派控制）、体育（不同比赛但同组出线/冠军）、加密/金融（不同到期日的阈值关系）。
- **关系集**：只保留人工审计通过的跨 event 关系；每一条记录规则原文片段、两个 event 的 `endDate`、结算源、反例检查结果。
- **独立结果**：按不同关系簇计，同一对 event 的多个档/方向只算 1 个；同一关系簇在 14 天内重复出现，最多计 2 次（首次 + 一次复现），不能把每次扫描当独立结果。目标 ≥30 个簇；不足则如实记 N。
- **纸面执行**：每个组合最多 5 腿，按 CLOB ask/bid 的可成交深度逐腿成交；1 秒延迟；单腿最多 $500；部分成交按最坏情况退出；taker fee 按 `C×r×p×(1−p)` 逐腿计，p 用该腿实际成交价。
- **失败标准**（预先写死）：30 个簇的扣费后组合收益均值 ≤0；或可成交腿覆盖 <80%；或人工审计发现的语义错误率 >5%；或最大回撤 >总资金 10%；或结算后有任一组合支付低于其理论下界。任一触发即判不可用或缩到待选区。
- **对照**：同一批关系上跑“只做同 event 阈值阶梯”的对照，若对照的收益/机会数明显更高，说明跨 event 子集容量不足，应降级而不是硬做。

## 成本与容量

- **费用**：Polymarket taker fee = `C × r × p × (1−p)`；politics/finance 约 `r=0.04`，crypto `r=0.07`，sports `r=0.05`，其他板块 0.04–0.05；maker 不收费。买 NO 时 p 用 NO 成交价，不能拿 YES 价格代入。
- **单组合成本示例**：2 腿组合、两腿各 50¢、r=0.04，单腿费 1¢/份（`0.04×0.5×0.5`），两腿 2¢；若组合毛边际只有 1–2¢，费后可能为负。4–5 腿组合的费用按腿累加，必须逐腿算，不能用 2% 的整篮近似。
- **滑点/深度**：论文的 2.2% 平均是费后保证收益，但容量到 $113.7M；我们的单腿 $500、总 $2,500 远小于论文，深度不是主要约束，主要约束是关系出现频率和人工审计时间。
- **资金占用**：组合持有到结算，平均资金占用约 2–7 天（论文的 semantic 组合更长）；$2,500 全部占用时，按 3.5%/周粗算约 $87.5/周，但这是论文全样本的平均，不是跨 event 子集或当前市场的保证。
- **容量**：单组合 5 腿 × $500 = $2,500 上限；最多 1–2 个并发组合，避免超过单场所上限。月机会数未知；论文 42 天 125,095 个执行窗口，但跨 event 子集和人工审计会把可做数量压到很小。
- **粗略净收益**：若每个 2 腿组合毛边际 3¢、成本 1 美元、费后净 1–2¢（1–2%），$2,500 周转一次赚 $25–50；两周能做多少次取决于关系数，不能按论文的 3.5%/周直接年化。

## 风险

- **语义关系错误（最大风险）**：规则文本的“赢得提名”“成为总统”“在任”“退出”等词有细微条件；A⇒B 可能只在部分结果下成立。错误关系会把亏损组合当成套利。缓解：100% 人工审计、保留原文、找反例、只做无条件成立的支付约束。
- **结算源/日期不一致**：两个 event 的 `endDate` 或结算源不同，支付下界不成立；必须逐市场核对，不能把事件结束日当结算日。
- **部分成交/非原子执行**：多腿顺序下单，先成交的腿可能裸露；退出成本和撤单延迟会吃掉边际。缓解：单腿限额、最坏情况退出预算、不在深度不足时开始新组合。
- **费用与舍入**：taker fee 随 p 变化，低价 NO 腿的费用率可能高于直觉；平台舍入和最小 tick 也会改变边际。必须逐腿按实际成交价计费。
- **论文外推风险**：论文的 25.4% 执行率、累计资本回报 2.2%、3.5%/周来自特定样本和作者自建数据；跨 event 子集、当前竞争程度、API 延迟都不同。不能把论文结果当成本条的上界或保证。
- **模型/工具风险**：LLM 抽取关系可能产生幻觉；解析器可能把“同名不同届”“同一队不同比赛”误配。任何自动关系都必须可追溯到原文片段。
- **监管/平台风险**：Polymarket 的访问和结算受地区限制；本条不提供交易代码、密钥或账户操作。

## 门槛自查

1. **机制说得清**：满足。付款方是逐 event 定价的交易者；四类逻辑约束和对应组合的支付下界均已写出；不是“指标组合”。
2. **有免费数据能检验**：部分满足。Gamma/CLOB/data-api 免费免密钥，可前向记录规则、盘口和成交；但无免费历史全深度 L2，论文数据不可公开复现，只能从 2026-10-20 起自录。
3. **小资金能做**：满足。单组合最多 5 腿、单腿 $500、总额 ≤$2,500，无杠杆；容量受关系出现频率限制，不受资金规模限制。
4. **不重复**：满足（待主审确认）。与 `dot-007` 同 event 阈值阶梯、`dot-006` 同 event NegRisk 完整集、`dot-005` 跨场所等价支付、`known/A-A3-poly-cross-market` 的关键变量不同；本条的关键变量是**跨 event 的逻辑约束图 + 整数组合**。
5. **扣成本后粗算够用**：有条件。论文费后累计资本回报 2.2%、峰值资本约 3.5%/周，但跨 event 子集未单独报告；按 2 腿 3¢ 毛边际、2¢ 费后净额估算，单次 1–2% 为正，但必须用前向审计确认关系频率和可成交性。
6. **两周内能检验**：部分满足。已给出 14 天、≥30 个关系簇、逐腿费用、1 秒延迟和失败标准；跨 event 关系是否能在两周内凑够 30 个簇未知，不足则如实记 N。
7. **出处可查**：满足。论文 PDF、Polymarket 费用文档、Gamma/CLOB 端点均有链接和访问日期；论文数字标注“来源自报，未核实”，未把未复核的实时价格写成本条证据。
