> 作者：Muse 直属 agent（muse-agent-10）｜ 补位第 2 批

## 一句话

大鲸鱼可能把仓位拆到多个钱包（2024 年 Théo 一人四钱包是公开案例）；用行为特征把碎片钱包聚回一个实体，当簇的聚合新仓超过阈值时跟随其方向——市场对每个小钱包都不反应，对聚合后的真实意图才反应，而那正是没被定价的信息。

## 钱从哪里来

付钱的是只盯单钱包阈值的市场参与者与警报体系。现有鲸鱼追踪（排行榜、单笔大单提醒）都以单钱包为单位：一个实体拆成 4 个钱包各下 750 万，和一个钱包下 3000 万，信息量相同，但前者在公开版面上只是四笔"中等交易"，价格反应慢得多。Théo 的四钱包（Théo4、Fredi9999、PrincessCaro、Michie）在 2024 年合计下注约 3000 万美元、获利约 4800 万美元（Bloomberg/WSJ/NYT 报道），身份是事后才被拼出来的。聚类把"事后拼图"提前到建仓当下：簇的聚合仓位暴露真实信念强度，跟随者在价格补涨/补跌完成前入场。

## 规则

- 聚类特征（同一候选簇）：①钱包首次出现时间相近（同一周内新建/首交易）；②在 ≥2 个相同市场同向交易且时间间隔常在数小时内；③单笔金额量级相近；④历史盈亏曲线高度同步。满足 ≥3 条判为同一实体簇。
- 触发：簇内钱包在某市场的聚合净新建仓 ≥5 万美元，而单钱包均 <2 万美元（即单看每个钱包都不触发常规鲸鱼警报），跟随者 1 小时内同向建仓，持有到结算。
- 排除：已知做市/套利钱包簇（双边高频、持仓瞬时翻转的）不跟，只跟方向性持有到结算附近的簇。
- 结算规则要点：Polymarket 二元市场按市场页规则由 UMA 乐观预言机裁定，胜方份额按 1 美元赎回、负方归零；结算数据源以各市场规则原文为准。

## 证据

- Théo 四钱包案：四钱包同属一名法国交易员、合计约 3000 万美元押特朗普、获利约 4800 万美元（NY Post 已读，引平台/WSJ 口径）；"分散下注以避开单个地址深度"只见于二手汇总（ai-trading-ranked，摘要），NY Post 原文未给这一解释。这说明大额信念可以分散在多个钱包、单钱包视角会低估其聚合意图，且在 Polymarket 真实发生过、金额巨大。
- 可行性佐证：Polymarket Data API 免密钥，实测 `/trades?limit=1` 返回 `proxyWallet`、`side`、`size`、`price`、`timestamp` 等字段（2026-10-21 打开）；开源文档另列 Get Leaderboard / Positions / Trades / Holders。聚类所需的地址、时间、方向、金额可直接取得；"钱包首现"需从可见成交历史推导，历史深度受单市场约 2 万笔限制。
- 诚实标注：Théo 簇的识别是事后（媒体调查+排行榜拼图）；"事前用行为特征聚出同等簇"的精确率尚无公开实测，本条核心不确定性在此，检验的第一关就是它。
- 本次复核（2026-10-20，Data API）：四个公开地址的全时 PnL 合计 $47,852,091（Theo4 $22,053,934 + Fredi9999 $16,619,507 + PrincessCaro $6,083,643 + Michie $3,095,008），与 NY Post“约 $48M”对上；四地址在 2024 大选主市场均为净 Yes（Trump）方向。但 API 只能给出可见成交，不能证明四地址同一控制人；“钱包首现同一周”在可见成交上不成立（Fredi9999 首笔 2024-08-03、Theo4 首笔 2024-10-14），聚类方法未在已知阳性对照上复现。

## 数据

Polymarket Data API：全市场成交（钱包地址、时间戳、方向、金额；单市场约最近 2 万笔）、钱包持仓与历史、市场持有者名单，公开免密钥，限流约 1000 请求/10 秒（成交 200/10 秒）；Gamma API 提供市场规则与结算状态。2024 大选市场成交可作阳性对照集。资金来源图谱（Polygon 链上 USDC 转账）可作辅助特征，但公开 RPC 拉全量转账成本高，本检验以行为聚类为主、资金图谱未验证。

## 两周内怎么检验

①阳性对照：对 2024 大选主市场用当时的成交数据跑聚类，看能否在不看名单的前提下把 Théo 四钱包聚为一簇（能聚出=方法有效性的下限证据）。②前向回测：对其余近 3 个月已结算市场跑聚类，抽 30 个簇人工核对（钱包历史、同步性）估精确率；③跟随收益：对每个簇-市场事件，记录簇聚合建仓均价与结算结果，算扣往返成本（GUIDE §8 口径）后净收益；独立事件按事件计（同一事件的多个市场只算一个），目标 ≥30 个；失败标准：精确率 <50%，或净收益中位数 ≤0，或合格事件 <30 个。

## 成本与容量

数据与计算成本为零（API 免费，聚类是离线批处理）。交易成本与普通跟随相同（价差+滑移），且入场时价格尚未被簇流充分推动，理论滑移小于跟随已暴露的大单（未实测，标不确定）。容量：只跟成交量靠前市场的簇信号，5000 USDT 本金单事件 100–250 美元可执行。

## 风险

①误聚风险：无关钱包被错误并簇（跟错方向）或真簇漏检（错过信号），精确率是生死线；②实体反制：知道被聚类的鲸鱼可故意制造假同步行为诱导跟随；③信号衰减：此法公开后拆单方会改用更分散的行为模式；④跟随策略通病：簇方向错误时持有到结算亏损可达全额；⑤与条目 muse-922 的区别须守住：那条跟"已知高分钱包"，本条检"未知隐藏实体"，若评审认为同族可合并处理。

## 改进了什么

## 门槛自查
1. 机制说得清：满足。大实体拆单使单钱包视角系统性低估其信念强度，价格对聚合意图反应滞后；聚类还原意图，跟随者赚这段滞后。
2. 有免费数据能检验：满足。Data API 提供聚类所需全部字段且免密钥，另有 2024 大选阳性对照集。
3. 小资金能做：满足。跟随单 100–250 美元量级，5000 USDT 可执行。
4. 不重复：满足。与 known/C-C1-whale-net（永续大户净持仓总量，不做身份聚类）不同；与 S-S1-orderflow（匿名聚合订单流）不同：本条核心是钱包身份聚类；与 dot-016（BTC 永续订单流，且已被成本筛否决）不同；与本队 muse-922（跟随已评分的已知钱包）机制不同：本条先检测隐藏实体再跟随，付钱方是"只看单钱包"的市场。
5. 扣成本后粗算够用：不确定。聚类精确率与跟随滑移均未实测，检验第一关即精确率，不硬编数字。
6. 两周内能检验：部分满足。阳性对照+历史回测两周内可完成，但目标须按事件去重（同一事件多市场只算一个）；去重后 ≥30 个独立事件是否可达未验证。
7. 出处可查：部分满足。Théo 金额为媒体/平台口径（本次用 Data API 复核四地址全时 PnL 合计 $47.85M，但“$30M 下注”口径未复现）；Data API 能力已由官方文档核实；聚类方法与精确率无公开实测。
