# 回放汇总：quant-002

条目：`bots/quant/entries/quant-002-tom-monday-oos-counterevidence.md`（补充 E-E2-turn-of-month，负证据）。
结论：2022-01-01..2024-12-31，8 个日历规则版本 × 2 种可成交价 = 16 个结果，按每边 0.30% 全部为负；建议把 E-E2 的 BTC/ETH 现货版本降级或退回，本条只按负证据记“补充采纳”，不按可交易策略收录。

## 如何复现

- 脚本（本目录）：`fetch_data.py`（下载/缓存 K 线）、`backtest.py`（回放）、`verify_results.py`（逐笔重算/回撤/字段自检）、`verify_sources.py`（出处复核）。
- 依赖：`python3` + `pandas` + `numpy`；只用公开免密钥 HTTP，无需环境变量或密钥。
- 运行顺序：
  ```bash
  cd bots/quant/replay/quant-002
  python3 fetch_data.py        # 首次约 1–7 分钟（含 2 个币的 1d/1h 分页）；之后读 _cache/
  python3 backtest.py          # 约 8 秒；写 results_variants.csv / trades.csv / placebo.csv
  python3 verify_results.py    # 约 2 秒；逐笔复算并自检条目字段，PASS/FAIL
  python3 verify_sources.py    # 约 60 秒；写 _cache/verify_stdout.txt
  ```
- 参数（全部，不只最佳）：成本 `0.30%/边`（GUIDE §9）；主成交价 `next_open` = 持有首日 00:00 UTC 日线开盘价、最后持有日次一日 00:00 UTC 开盘价；敏感性成交价 `first_hour_vwap` = 首日 00:00–01:00 UTC 小时 K 线的 `quote_volume/volume`（真实成交 VWAP）。规则：TOM 精确 = 月末最后 1 日 + 次月 1–3 日；TOM 原始错位 = 次月 1–4 日；周一精确 = 周一 00:00 到周二 00:00 UTC；周一原始错位 = 周二。无拟合参数。
- 数据下载地址（访问 2026-10-21，全部 HTTP 200）：
  - 日线：`https://data-api.binance.vision/api/v3/klines?symbol=BTCUSDT&interval=1d&startTime=1640995200000&endTime=1735689599999&limit=1000`（分页；ETHUSDT 同结构）
  - 1h：`https://data-api.binance.vision/api/v3/klines?symbol=BTCUSDT&interval=1h&startTime=1640995200000&endTime=1735689599999&limit=1000`（分页；ETHUSDT 同结构）
  - 月包样例：`https://data.binance.vision/data/spot/monthly/klines/BTCUSDT/1d/BTCUSDT-1d-2024-12.zip`（31 行 × 12 列；ETHUSDT 同结构）
  - 逐笔复核：`https://data-api.binance.vision/api/v3/aggTrades?symbol=BTCUSDT&startTime=1728432000000&endTime=1728435599999&limit=1000`（2024-10-09 00:00–01:00 UTC，分页取完）
- 数据本身起点：2022-01-01（日线、1h 均覆盖到 2024-12-31）。`aggTrades` 在该免密钥端点只回溯到 2024-10-08，所以逐笔复核用 2024-10-09；这只用于验证“开盘价/VWAP 是真实成交”，不改变回放窗口。
- 开发窗口：`2022-01-01..2024-12-31`。2021 及以前、2025-01-01 以后没有下载、没有跑、没有报告。
- 切分依据：GUIDE §9 的加密开发窗口；规则在第 1 轮已冻结，本条把 2022、2023、2024 三个自然年全部报告（见 `results_variants.csv` 的 `y2022_pct`/`y2023_pct`/`y2024_pct`），没有用 2025+ 数据挑参数。2024 是时间上最后一年的“较严”子段，但不是从未见过的盲样本；真正的盲样本只能靠 2026-10 之后的前向记录。

## 成交和成本

- 成交价和时点：Binance 现货没有 Polymarket 式的 CLOB；本条按 GUIDE §9 的加密口径，主口径为“信号出现后的下一根日线开盘价”，并用 aggTrades 逐笔复核该开盘价/VWAP 是真实成交。日历信号在当天开盘前已知，所以 TOM 在窗口首日 00:00 UTC 开盘买、在最后持有日次一日 00:00 UTC 开盘卖；周一在周一 00:00 开盘买、周二 00:00 开盘卖。敏感性口径用首小时 VWAP（真实成交的加权价），不是 CLOB 中间价。
- 无前视：规则只用日历；成交在信号之后的第一根 K 线开盘。敏感性口径的 VWAP 也只用 00:00–01:00 已发生的成交。
- 全部成本：手续费/价差/滑点合并按 `0.30%/边`；现货无资金费。净单次 = `(1 + p1/p0 - 1) × (1-0.003)^2 - 1`。日线净值按每日收盘盯市，含浮亏。
- 资金和容量：每个变体只做单币，最多 2,500 USDT（单场所上限），其余现金，不加杠杆、不做空。若要同时做 BTC 和 ETH，两者合计不超过 2,500 USDT（例如各 1,250），避免把 5,000 全放在 Binance 一个场所。日历窗口只占约 13–14% 的日历日，容量不是瓶颈。

## 汇总结果

- 独立结果数及计法：TOM 每个自然月 1 个（35 个可用窗口）；周一每个 ISO 周 1 个（157 个可用窗口；错位版本 156 个）。均 ≥30。碰到 2022-01-01 或 2024-12-31 边界的截断窗口已剔除。
- 扣成本后净收益：主口径 8 个版本全部为负，3 年连乘区间 `-8.34%`（BTC TOM 错位）到 `-74.33%`（ETH 周一错位）；主变体 BTC 周一精确 `-38.54%`（年化 `-14.99%`）。敏感性首小时 VWAP 下 8 个版本也全部为负（`-11.97%` 到 `-74.03%`）。16/16 为负。生成命令：`python3 backtest.py`；产物：`results_variants.csv`、`trades.csv`、`placebo.csv`。
- 最大回撤：主变体 BTC 周一精确 `-55.72%`（日线，含浮亏，2,500 USDT 单币袖套口径）；最差变体 ETH 周一错位 `-79.71%`（日线）。账户级（2,500 袖套 + 2,500 现金）主变体为 `-29.33%`、最差 `-44.24%`（`verify_results.py`）。全部见 `results_variants.csv` 的 `max_dd_pct`。
- 对 5,000 USDT 的年化贡献：主变体 `-14.99% × 2,500 / 5,000 = -7.49%`；最差变体 `-36.46% × 2,500 / 5,000 = -18.23%`。见 `contribution_pct`。
- result：`负`（16/16 扣 0.30%/边后为负，独立结果 ≥30）。
- 不可靠或失败原因：这是反证，不是正策略。0.30%/边下没有版本为正；毛收益层面 BTC 周一精确是唯一接近显著边界的版本（+0.36%/窗口，t=1.21，单边 p=0.114，placebo p=0.145，盈亏平衡约 0.18%/边，低于 GUIDE 的 0.30%）。BTC TOM 错位毛均值更高（+0.47%/窗口），但 t=0.56、单边 p=0.289、placebo p=0.523，不显著；其余版本毛均值在 −1.11% 到 +0.34% 之间。2024 单年 BTC/ETH 周一精确分别为 +13.68%/+29.51%，但 3 年合计仍为负，不能据此翻案。
