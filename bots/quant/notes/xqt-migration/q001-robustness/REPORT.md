# quant-001 多重检验稳健性：DSR + PBO（预先指定 106 个闸门）

## 1. 目的与协议

对 quant-001（VM 动量 × BTC 趋势总开关）做诚实的多重检验评估。数据、VM 基准和 4 折逻辑直接复用 `../reproduce.py`（公开 Binance 日线，免密钥；下载缓存 `./_data/`，不入库），不修改原脚本。

- 4 个 OOS 折：2022-12-31～2023-12-30、2023-12-31～2024-12-29、2024-12-30～2025-12-29、2025-12-30～2026-10-13；每折前 250 天热身，只统计测试日。
- 每边成本 0.30%；权重在 t−1 收盘决定、赚 t 日收益；现货多头、不加杠杆。
- 指标：4 折日收益拼接后的 compound、CAGR、Sharpe（日频 ×√365）、路径最大回撤、平均仓位。

基线核对：本脚本的 VM 基线 compound +237.1525%、CAGR 37.8172%、路径回撤 −22.1166%，与 `../results.csv` 完全一致。注意 `results.csv` 的 `mean_sharpe=1.2496` 是“4 折 Sharpe 的均值”，本报告按要求用拼接日收益算 Sharpe，基线为 1.3232；两者口径不同。

## 2. 预先指定的闸门族（结果计算前写入脚本头）

每个变体 = 同一 VM 权重 × 一个 BTC 日线开关（前一日为“开”才持有，否则全现金）。

| 族 | 定义 | 变体数 |
|---|---|---:|
| 无闸门 | VM 基线 | 1 |
| SMA | `close ≥ SMA(n)×(1+b)`，n∈{5,10,15,20,30,40,50,75,100,125,150,200}，b∈{−1%,0,+1%} | 36 |
| EMA | 同上，用 EMA(n) | 36 |
| SAR | `close ≥ SAR(af,max_af)`，af∈{0.01,0.02,0.03}，max_af∈{0.10,0.15,0.20} | 9 |
| CCI | `CCI(n) ≥ thr`，n∈{10,20,40}，thr∈{−50,0,50} | 9 |
| %B | `%B(20,2) ≥ thr`，thr∈{0,0.2,0.4,0.6,0.8} | 5 |
| Donchian | `close > 前 n 日最高收盘`，n∈{10,20,30,60,90} | 5 |
| ROC | `n 日收益 > 0`，n∈{10,20,30,60,90} | 5 |
| **合计** | | **106** |

SAR(0.02,0.15) 是私有仓库的领先者，仍按原参数放进族内，不是看到结果后追加。

### 3.2 Deflated Sharpe Ratio（Bailey & López de Prado 2014）

输入：T=1383 个 OOS 日；族内 trial Sharpe 的方差 Var[SR_daily]=0.00019021（sd=0.013792，年化方差 0.069425）；最佳变体日收益 skew=6.2934、kurtosis=71.7656。

公式：
`SR0 = sqrt(Var[SR]) × [(1−γ)Φ⁻¹(1−1/N) + γΦ⁻¹(1−1/(N e))]`，γ=0.577216；
`DSR = Φ((SR_hat−SR0)√(T−1) / √(1 − skew·SR_hat + ((kurt−1)/4)·SR_hat²))`。

| 变体 | N（试验数） | Sharpe（年化） | SR0（年化） | DSR | z |
|---|---:|---:|---:|---:|---:|
| SAR(0.02,0.10)（最佳） | 106 | 1.615309 | 0.672164 | 0.991354 | 2.380452 |
| SAR(0.02,0.10)（最佳） | 224000 | 1.615309 | 1.202328 | 0.851374 | 1.042343 |
| SAR(0.02,0.15) | 106 | 1.586090 | 0.672164 | 0.989719 | 2.315946 |
| SAR(0.02,0.15) | 224000 | 1.586090 | 1.202328 | 0.834593 | 0.972476 |

在 106 次试验口径下 DSR>0.95；按私有仓库约 22.4 万次搜索口径，两个 DSR 都低于 0.95。

### 3.3 PBO（CSCV）

S=16 个连续块（每块 86–87 天），枚举全部 C(16,8)=12,870 个 IS/OOS 切分。

| 指标 | 值 |
|---|---:|
| PBO（IS 最优的 OOS 排名落在后半） | 0.3810 |
| 切分数 | 12,870 |
| IS 最优的 OOS 排名中位数 | 72.0 / 106 |
| 平均 logit λ | 0.6631 |

即约 38.1% 的切分里，样本内最优闸门在样本外落到后半区；存在明显的选择/过拟合风险。

### 3.4 配对 block bootstrap（每个闸门 vs VM 基线）

循环块 bootstrap，块长 20 天，B=4,000，seed=20261020，单侧 H1：闸门 > 基线。

- raw p<0.05：均值差 0/105；Sharpe 差 0/105。
- Holm p<0.05：均值差 0/105；Sharpe 差 0/105。
- BH p<0.05：均值差 0/105；Sharpe 差 0/105。
- 最小 raw p（均值差）：SAR(0.02,0.10) 0.36416；SAR(0.02,0.15) 0.43189。
- 最小 raw p（Sharpe 差）：SAR(0.02,0.10) 0.10447；SAR(0.02,0.15) 0.14271。
- 经 Holm 校正后，没有任何闸门在收益或 Sharpe 上显著。

### 3.5 胜出比例（105 个闸门 vs 基线）

| 口径 | 胜出数 | 比例 |
|---|---:|---:|
| Sharpe 更高 | 26/105 | 24.8% |
| 路径最大回撤更小 | 94/105 | 89.5% |
| compound 收益更高 | 6/105 | 5.7% |
| Sharpe 和回撤同时更好 | 26/105 | 24.8% |

中位数变化：Sharpe −0.092、路径回撤 +2.66 pp（即回撤更小）、compound −67.4 pp。

## 4. 判定

- **收益/Sharpe 的“改进”不成立。** 只有 24.8% 的闸门 Sharpe 高于 VM、5.7% 收益更高；配对 bootstrap 经 Holm/BH 校正后 0/105 显著；PBO=0.3810。
- **回撤/仓位的改善是稳健的，但主要是降风险而非增收益。** 89.5% 的闸门降低路径最大回撤，代价是平均仓位从 0.2886 降到约 0.18–0.24，收益中位数明显下降。
- **SAR 的“领先”不能按收益优势采信。** DSR 在 N=106 时 0.991，但在 N=224,000 时 0.851；PBO 0.381；配对检验不显著。按评审关注的私有搜索规模，SAR 的优势没有通过多重检验。
- 因此 quant-001 若保留，只能表述为“降低回撤的风控改进”；“gate improves VM”在收益/Sharpe 维度不成立。

## 5. 限制

1. 样本外仅约 3.8 年、3 个币、日线，2023–2024 牛市贡献大部分收益；4 折并非独立市场状态。
2. 本报告的 106 个闸门是公开预指定族，不是私有仓库的 22.4 万次搜索。用本族 trial Sharpe 方差去代入 N=224,000，很可能低估真实搜索的 SR0，因此 0.851/0.835 是偏乐观的上界。
3. DSR 假设试验近似独立；族内变体高度相关，N 与 Var[SR] 的解释都是近似的。
4. CSCV 假设块可交换，用 Sharpe 作为绩效；重尾（最佳变体 kurtosis 71.77）与高度相关变体会影响 PBO 的精确值。
5. Bootstrap 块长固定 20 天、单侧检验，结果对块长和重采样方案有一定敏感性；校正只覆盖本族 105 个闸门，不覆盖私有搜索。
6. 全部为回测，无实盘/纸面交易；未计现金利息，成本只按每边 0.30% 计。

## 6. 对 quant-001 表述的建议（不修改 entry）

> 在 2022-12-31～2026-10-13 的 4 折样本外（0.30%/边）上，BTC 趋势闸门对 VM 的稳健改进是回撤/仓位，而不是收益：105 个预先指定闸门中 94 个（89.5%）降低了拼接路径最大回撤，但只有 26 个（24.8%）Sharpe 高于 VM、6 个（5.7%）收益更高；配对 block bootstrap 经 Holm/BH 校正后没有一个闸门在收益或 Sharpe 上显著。SAR(0.02,0.15) 的 DSR 在 106 次试验下为 0.990，但按私有仓库约 22.4 万次搜索计算降至 0.835，PBO=0.381。因此本条应表述为“降低回撤的风控改进”，不能表述为“提高收益/Sharpe 的改进”；收益优势未通过多重检验。
