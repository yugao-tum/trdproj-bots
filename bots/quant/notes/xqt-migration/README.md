# x-quant-trials 迁移：规则、复现与诚实说明（2026-10-20）

## 来源和可查性
- 此前的研究在使用者的**私有**仓库 `yugao-tum/x-quant-trials`，评审打不开，所以本目录**不引用它作证据**。
- 本目录给出：冻结规则（下文）、`reproduce.py`（只用 pandas/numpy，从公开免密钥的 https://data.binance.vision/ 下载 BTCUSDT、ETHUSDT、SOLUSDT 日线，2020-12-31 至 2026-10-13），以及 2026-10-20 实际运行的输出 `results.csv`。原始行情不入库（`_data/` 已忽略）。
- 运行：`python3 reproduce.py`，约 3 分钟（下载 3×71 个 zip）。
- 复现核对：用公开数据重算，结果与私有仓库日志对得上：VM 基准 10bp 下私有日志 +277.2% / −14.7%，本次 +275.8% / −14.7%（差异来自基准在私有日志里按全样本计算再切片，这里按每折重算）；0.30% 下私有 +238.4% / −15.8%，本次 +237.2% / −15.8%；SAR 闸门私有 +314.2/−9.8 与 +264.6/−10.7，本次完全一致；CCI 闸门私有 +286.4/−11.1，本次 +286.4/−11.1。%B 闸门私有日志 +263.6/−13.0，本次 +284.0/−13.0，**未能复现回报**（公式细节可能不同），不作证据。

## 冻结的检验协议
- 4 个滚动样本外测试折：2022-12-31～2023-12-30、2023-12-31～2024-12-29、2024-12-30～2025-12-29、2025-12-30～2026-10-13（共约 3.8 年）。每折从测试起点前 250 天开始重算（热身），只统计测试日。
- 指标：compound = 4 折收益连乘 −1；cagr = 按 OOS 天数折年；worst_fold_dd = 单折内最大回撤的最差值（私有日志用的口径）；path_dd = 4 折拼接后的整条净值最大回撤（更严，本次新增）。
- 成本：按权重变动 |Δw| 每边 0.10%（基础）和 0.30%（GUIDE 的每边成本）。权重在 t−1 收盘决定、赚 t 日收益；只做现货多头、不加杠杆；平均仓位见 `avg_exposure`，其余是现金（未计利息）。

## 规则
- **VM 基准（=known T-T2-vm 同一机制）**：BTC/ETH/SOL；动量 = 跳过最近 1 天的 30 日收益；持有动量 >0 的币等权；整体仓位乘以 min(1, 15% ÷ 前 4 周“未缩放组合”周收益年化波动)；每 5 个交易日调仓。
- **M1 闸门**：在 VM 权重上乘以一个 BTC 日线开关（前一日为“开”才持有，否则全部现金）。私有仓库里试过 300 多种指标作开关，本目录只复现三个被选出的领先者（SAR(0.02,0.15) 收盘在 SAR 上方；CCI(20)≥0；%B(20,2)≥0.4）和三个**本次事先指定、未经挑选**的简单开关（BTC 收盘 ≥ 50/100/200 日均线）。
- **M2 广度闸门（PAA 式）**：BTC/ETH/SOL 的 60 日收益 >0 的数目 ≥2 才持有，持有其中为正的等权；否则全部现金；按 60 日波动把组合稀释到 30% 年化；每 5 日调仓。
- **M3 日历**：单币（BTC 或 ETH）只在月末最后 1 天加月初前 3 天持有（TOM），或只在周一持有。`calendar_exact` 是按日历精确持有当天；`orig_shift` 是私有仓库原代码（把窗口错后了一天：实际持有月初第 1～4 天、周二），两种都列出。

## 必须一起读的限制
1. **大量多重检验**：私有仓库 319 个“W”批次的结果表合计约 22.4 万行参数组合，最后留下 303 个“孪生”（VM 或 VCB 基础 × 一个指标开关）。领先者的回报优势很可能主要来自挑选；事先指定的均线开关只稳定地降低了仓位和拼接路径回撤（−22.1% → −19.1%～−20.1%），回报反而更低。
2. **原项目结论是 NOT READY / KEEP VM**：没有任何候选通过原项目全部晋级门槛（尤其是按日历周记录的纸面交易没有完成）。私有日志明确要求“不引用纸面交易数字”，本目录也不引用。
3. 样本外只有约 3.8 年、3 个币、日线；“跨引擎一致”（vectorbt/Basana/PyneCore）是同一逻辑的重算，不是独立数据。
4. 这些都是回测，不是实盘；没有交易，没有用任何密钥。
