# quant-013 真样本外回测（按预注册失败标准）

## 结论

**TRUE OOS（2021-05-04 .. 2025-08-14）：BTC FAIL，SOL FAIL。**

两者都触发预注册的第 1 条失败标准（事件级 3 日净收益中位数 ≤ 0），并且规则净值同时跑不赢同期买入持有（第 2 条）。事件数 109 ≥ 30，所以不是“样本不足”，是经济性失败。

- BTC：109 个事件，事件级 3 日净收益均值 **+0.09%**、中位数 **−0.40%**、胜率 **45.87%**；规则净值 **−33.27%**（140 笔，最大回撤 −63.61%，暴露 20.72%），同期 BTCUSDT 买入持有 **+122.36%**（最大回撤 −76.63%）。
- SOL：109 个事件，事件级 3 日净收益均值 **+0.14%**、中位数 **−0.25%**、胜率 **48.62%**；规则净值 **−74.03%**（140 笔，最大回撤 −84.31%，暴露 20.72%），同期 SOLUSDT 买入持有 **+351.43%**（最大回撤 −96.27%）。

条目样本内 +32.69% 的净值可以被逐项复现，但它不是样本外证据：按条目自己的预热口径复跑得到的事件级中位数本来就是负的（BTC −0.41%，SOL −0.23%），且完整样本外一跑就转为明显亏损。**按预注册标准，quant-013 不通过。**

## 方法（未改任何参数）

- 溢价：`p_t = (CB_BTC_t / (BN_BTC_t × CB_USDT_t) − 1) × 10000`，全部用已收盘日线。
- z 分数：`z_t = (p_t − mean(p_{t−30..t−1})) / pstdev(p_{t−30..t−1})`，前 30 个交易日、不含当日、总体标准差；不足 30 日不做信号。
- 进场：`z_t ≥ +1.0` → 下一个 UTC 日开盘买入；出场：之后任一交易日 `z_t < 0` → 次日开盘卖出，或持有满 10 个交易日无条件卖出。
- 脱锚过滤：信号日 `|U_t − 1| > 100bp` 时当天信号作废、不开新仓。
- 成本：每边 0.30%，往返 0.60%；单标的、单腿、无杠杆、满仓 sleeve；不做空、不加仓。
- 事件计数：`z ≥ +1` 的信号日，若相邻信号日的**交易日索引差 ≤ 3** 则并入同一段；每段的第一个信号日算 1 个独立事件。BTC 与 SOL 共用同一个 BTC 溢价信号，因此事件数相同。这个口径复现了条目证据里的 29 个事件。
- 事件收益：信号日次日开盘进，信号日 +4 收盘出（即入场日起第 3 个交易日收盘），扣 0.60%。这个口径与条目证据里的 BTC `+0.79% / −0.41% / 48%`、SOL `+1.43% / −0.23% / 48%` 完全对上（见下方“样本内复核”）。
- 规则净值：日度 mark-to-market；若区间结束时仍持仓，按最后收盘价并扣卖出侧 0.30% 强制平仓。最大回撤用日度净值；暴露 = 持仓天数 / 区间交易日数。B&H = 同区间、同标的 Binance 日线收盘到收盘；B&H 最大回撤用同一条日线。
- 未做阈值敏感性、未搜索参数；预注册只认 1.0，故只跑 1.0。

## 样本内复核（为什么条目是 29，我们主口径是 31）

条目没有用 2025-08-15 之前的数据做 z 预热。它从 2025-08-15 起算溢价，首个 z 出现在 2025-09-14，因此只有 **29** 个事件、首事件 2025-09-30。按这个口径原样复跑：

- 29 个事件；BTC 事件均值 **+0.79%**、中位数 **−0.41%**、胜率 **48.28%**；SOL **+1.43% / −0.23% / 48.28%**。
- 规则 **39** 笔，BTC 净值 **+32.69%**（最大回撤 −13.19%），SOL **+30.25%**（最大回撤 −13.90%）；BTC B&H **−28.74%**。

这与条目第 57–59 行的数字逐项一致，说明本脚本的公式、成本、事件合并和事件收益口径没有实现偏差。

主口径必须用 2021 起的完整历史做 z 预热（真样本外不能用未来数据），所以同一个 2025-08-15..2026-09-30 窗口得到 **31** 个事件、**41** 笔，BTC **+31.77%**、SOL **+39.12%**。这一差异来自窗口开头的预热差异，不是数据或代码错误。**即使按条目自己的 29 事件口径，事件级中位数也已经是负的**（BTC −0.41%，SOL −0.23%），已经触发第 1 条失败标准；+32.69% 只是少数大赢家造成的样本内均值/净值。

## 判定

- **BTC：FAIL。** 109 个事件 ≥ 30；事件级中位数 −0.40% ≤ 0（第 1 条失败）；规则 −33.27% < B&H +122.36%（第 2 条也失败）。
- **SOL：FAIL。** 109 个事件 ≥ 30；事件级中位数 −0.25% ≤ 0（第 1 条失败）；规则 −74.03% < SOL B&H +351.43%（第 2 条也失败；即使拿 BTC B&H +122.36% 来比，仍然失败）。

所以这不是“样本不足”或“数据没取到”，而是在 109 个独立事件上、按预先写死的标准明确失败。样本内那条 +32.69% 的净值曲线不能支持该条目继续进入影子前向或模拟盘。

## 局限

- **数据对齐**：Coinbase 日线是 00:00–00:00 UTC，Binance 日线收在 23:59:59.999 UTC，两者收盘最多差约 1 分钟；本条没有做逐秒对齐。溢价中位数只有 0.33bp、sd 1.99bp，日线收盘时点差和 Coinbase `USDT-USD` 薄盘口的噪声与信号同量级，无法用日线数据排除。极端值 −19.72bp / +32.60bp 也可能是真实错位或数据噪声。
- **事件相关性**：事件按“≤3 个交易日合并”计数，但相隔 4 天以上的事件，其 3 日收益窗口仍可能重叠；109 个事件不是 109 份完全独立的信息。BTC 与 SOL 共用同一个 BTC 溢价信号，两者的收益也高度相关，不能把两个标的的 109 个事件当成两倍独立样本。
- **幸存者偏差**：只检验了 BTC、SOL 两个存活到今天的标的，没有纳入已退市、归零或流动性枯竭的币种；结论不能外推到“所有加密现货”。
- **多重检验**：条目的 30 日窗、阈值 1.0、`z<0` 出场是在同一段 2025-08-15..2026-09-30 数据上选的，条目还跑过 1.5/2.0 的阈值敏感性；本轮只做了一个预注册 OOS 检验，没有做多重检验校正。不过 OOS 的失败幅度很大（两项标准同时触发），校正也救不回来。
- **脱锚过滤未被检验**：全样本 `|U_t−1|>100bp` 的天数为 0，过滤器从未触发；因此本轮没有验证它在真实脱锚时是否有效，只能说它没有改变结果。
- **数据终点**：Binance 月度归档到 2026-09-30，Coinbase 到 2026-10-20；全区间没有包含 2026-10 的数据，但这不影响 TRUE_OOS。
