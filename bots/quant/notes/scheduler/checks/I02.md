## 4. Look-ahead / 成本 / 独立性 / 容量

- **Look-ahead**：q006-hist 的 Elo 只用目标赛事周之前已完成的比赛回放；价格只取 `[开赛−6h, 开赛−15m]`（敏感性 [−24h,−1h]）的已执行成交；赔付用 Gamma 最终 `outcomePrices`。没有用赛前窗口之后的成交或目标比赛结果去构造 Elo。✅
- **日期匹配偏差**：Sackmann 只有 `tourney_date`（赛事周起始），条目用 `[PM 比赛日−15天, PM 比赛日+2天]` 匹配，`date_lag_days` 为 −1..13；这是已知的**匹配偏差**，不是 look-ahead。REPORT 已披露，并另跑 `date_lag_days≤2` 子集（仍为负）。✅
- **成本**：回测买价 = 窗口内最后成交价 + 1¢，费 `0.05×ask×(1−ask)`；maker 返佣不计。条目规则写“卖价=mid+spread/2”，但历史回测实际用最后成交+1¢，两者不完全相同；条目在 `## 数据` 和 REPORT 的限制节已写明，gate 6 的结论是负的，不会因更差的真实 ask 翻正。✅（口径差异，不是伪造。）
- **独立性**：每场比赛只算 1 个结果；1366 笔触发对应 1366 场独立比赛（同一 event 的让盘/总分不入样）。✅
- **容量**：单场 ≤100 份且 ≤60 USDT；示例 ask 0.265–0.735 时约 26–74 USDT/场；2,500 USDT 场所上限和 5,000 总资金都放得下。但历史没有 L2 盘口，只有成交价，实际可成交量未实测。✅
- **失败处理**：预注册标准是“触发 ≥30 笔且每份净收益中位 ≤0”；本次 1366 笔、中位 −0.114895，判 **FAIL**。零成本敏感性仍 −0.100000，负结论不变。✅
