## 2. 方法（预先写死）

- **事件窗口**：Gamma `description` 的 `from … through …`（允许年份后无逗号）；`this-week-mar-10-16` 也可解析为 2026-03-10 至 2026-03-16，slug 回退仅作保险。
- **基准率**：同一海峡、**严格早于事件周起点**的最近 12 个完整 Mon–Sun 周总量，套入当期档位，`p_i=(k_i+1)/(12+n)`，n 为档数。事件周及以后的数据不进入模型。
- **市场首价**：该档 YES token 最早一条 `prices-history` 记录；**周起点价**：`t <= 事件周起点 00:00:00 UTC` 的最后一条记录。两者都按档归一化（除以各档价格之和）；某档无价格则该事件不进入对应 Brier。
- **Brier**：多分类 `Σ(p_i-y_i)^2`，y 取 Gamma `outcomePrices` 的 YES=1 档；差值定义为“市场 Brier − 模型 Brier”，正数表示模型更好。
- **交易规则**：只做 Bab el-Mandeb（条目明确不做 Hormuz）。NO 公允 = `1-p_model`；NO 吃单价 = `1-p_ref+0.01`（1¢ 半价差）；触发条件 `1-p_model >= NO吃单价 + 0.01`（条目 0.01 安全垫）。`p_ref` 优先取周起点价；若市场在周起点后才开市/无成交，取首价并在 `buckets.csv` 的 `entry_kind` 标记。每档 1 份。手续费按 GUIDE §8 地缘费率 **0**：`份数×0×p×(1-p)=0`；历史市场 `feesEnabled=false` 与此一致。
- **已实现毛利**：每份 NO = 兑付（NO 赢 1 / 输 0）− 成交价 − 手续费；亏损份额计入。若只算赢的份额，任何 NO 买单都正毛利，标准 (1) 会失去意义。
- **独立结果**：Brier 按 event 计；严格口径把同一周两海峡聚成 1 个观测（周内平均差），宽口径按 event 计。

## 4. 限制

- CLOB `prices-history` 是逐档**最后成交价**（fidelity=60 的抽样），不是可执行盘口；没有历史深度/挂单量。1¢ 半价差是预先假设，真实价差可能更宽或更窄。
- PortWatch 是**事后修订**后的当前值，不是事件当时的 vintage；2026-03 至 2026-05 有 9 个事件复算档位与 Gamma 结算不一致，这些事件的模型输入也可能被修订污染。
- 周起点价只在市场已于周起点前开市时有定义；部分早期 event 在周中才创建，交易 P&L 用首价回退，已在 `buckets.csv` 标记。
- 同一周两海峡高度相关；Brier 的严格口径只有 31 个周级观测，宽口径的 event 级 t 检验会高估独立样本量。
- Bab 只有 12 个已关闭事件，交易规则触发次数有限；中位毛利基于份额，不是基于独立 event。
- 费率按 GUIDE §8 地缘 0；若平台未来改费率，P&L 需重算。
