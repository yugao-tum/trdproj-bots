# quant-011 历史可成交价格回测

- 分支：`quant-review/q011-hist`
- 数据访问日：2026-10-20
- 结论：**FAIL**（161 个 triggered，≥30；主窗口中位净收益 ≤ 0，且每美元投入的总净收益为负）

## 结论

用 data-api 的已闭合市场成交记录，替代条目原先“历史平局价格不可得、只能前向记录”的缺口。五个联赛共 2,090 个带平局市场的 closed Polymarket 比赛 event；按日期 ±1 天 + 归一化队名匹配到 football-data 1,987 场（另有 2 个同一比赛重复 event 合并），匹配率 **96.6%**（2,019 / 2,090）；其中 **1,986 场**在主窗口内有成交价。Polymarket 平局结算与 football-data `FTR` 一致 **2,019 / 2,019（100.0%）**。

主窗口 `[T−6h, T]` 共 **161 场 triggered**：

- 净收益/份：中位数 **−0.2389**，均值 **−0.0525**，合计 **−8.4533**；
- 每美元投入总净收益 **−22.82%**；命中率 **18.6%**。

敏感性窗口 `[T−24h, T−1h]` 共 **164 场 triggered**：中位数 **−0.2389**、均值 **−0.0074**、每美元投入 **−3.21%**、命中率 **23.2%**。敏感性窗口里 E0 (+13.36%)、D1 (+16.75%) 为正，但总体仍为负，且两个窗口的中位数都 < 0。

概率评分（1,986 个 priced 比赛中 1,982 个有基准率）：

- Brier：基准率 **0.18578**，市场 **0.18487**（市场略好，差 −0.00091）；
- LogLoss：基准率 **0.55686**，市场 **0.55419**（市场略好，差 −0.00268）；
- 配对符号检验：基准率更好 988 场、市场更好 994 场，双侧 **p = 0.9106**，没有显著差异。

> 注：条目冻结的“净收益中位数 ≤ 0”对二元合约本身很容易机械成立（多数单注亏掉本金）。本回测即便改用“每美元投入总净收益”，仍为 **−22.82%**，所以 FAIL 不是中位数口径造成的。

## 数据与来源（均为免费、免密钥公开接口）

- Gamma closed events keyset：`https://gamma-api.polymarket.com/events/keyset?closed=true&tag_slug=<tag>&limit=100`（访问 2026-10-20，已读）。按联赛 tag 枚举；只保留带 full-time draw 市场的 event，排除 halftime/draw-at-half 等衍生 event。
- data-api 成交：`https://data-api.polymarket.com/trades?market=<conditionId>&limit=500&offset=N`（访问 2026-10-20，已读）。`side`、`price`、`size`、`timestamp`、`outcome` 均来自返回；按 timestamp 取窗口内最后一笔。
- football-data.co.uk 逐文件 CSV：`https://www.football-data.co.uk/mmz4281/<season>/<league>.csv`，season = 1718…2627，league = E0/I1/SP1/D1/F1（访问 2026-10-20，已读）。条目“数据”里把多个 season/league 拼在一个 URL 的写法是错的；这里按文件逐个取，未改动条目。
- 条目原文：`bots/quant/entries/quant-011-soccer-draw-pricing.md`（已读）。

## 方法（脚本头已预声明）

- **联赛**：E0（英超）、I1（意甲）、SP1（西甲）、D1（德甲）、F1（法甲）；即条目用的 E0/I1 加另外三个同时有 football-data CSV 和 Polymarket closed 平局市场的 top-5 联赛。
- **基准率**：`qD = (1/B365D) / (1/B365H + 1/B365D + 1/B365A)`；按 0.04 宽 qD 桶（从 0.14 起）统计历史平局频率。只用该比赛赛季**严格之前**的赛季（expanding walk-forward，无同赛季泄漏）；同联赛同桶 n ≥ 30 才用，否则回退到五联赛合并的同桶 prior 样本（仍需 n ≥ 30）。
- **决策时间**：`T = gameStartTime − 1h`。主窗口 `[T−6h, T]`；敏感性 `[T−24h, T−1h]`。
- **可成交价**：公共数据只有成交打印，没有闭合市场的历史盘口；用窗口内最后一笔平局 YES 成交价（NO 成交按 `1−p` 转换），可执行 ask 近似为 **last YES print + 0.01**（1¢ 半价差）。窗口内无成交 = unpriced，不填单。
- **交易规则**：ask 在 `[0.15, 0.30]`，且 `ask ≤ 基准率 − 0.02`（0.02 为条目自己的成本缓冲：约 0.008 费 + 0.01 半价差，向上取整）。每场 1 份、持有到结算；一场比赛算 1 个独立结果。不满足不交易。
- **费用**：GUIDE §8，体育 taker 费率 0.05；每份 `fee = 0.05 × ask × (1−ask)`，`net = draw_payout − ask − fee`。1¢ 半价差已含在 ask 里，不重复扣。
- **结算校验**：Gamma draw 市场 `outcomePrices` 对 football-data `FTR`；本样本 100% 一致，mismatch 为 0，故未触发剔除。

## 对门槛 5、6 的意义

- **门槛 5（扣成本后够用）**：现在有了真实的 closed-market 成交价与费用后的结果，不再只是粗算。结果是负的：161 次触发、每美元投入 −22.82%。因此门槛 5 **不满足**；条目里“英超单桶扣成本后 +13.1%”的粗算没有被历史可成交价格复现。
- **门槛 6（两周内能检验）**：条目原来说 Polymarket 历史平局价格不可得，只能前向记录。data-api 的 closed 市场成交记录已经解锁这件事：本回测有 161 个触发样本，超过 30 的门线，不需要再等两周前向记录。若主审仍要求前向证据，这份历史检验应作为“先验失败”，不能再把“未回测”当作待核理由。
- 条目原文的“没有跑过 Polymarket 回测，因为历史平局价格不可得”在 **closed market + data-api trades** 路径下已经不成立；本次未修改条目，只把证据放在本目录。

## 限制

1. **没有历史盘口**：closed 市场只有成交打印。ask 用 last print + 1¢ 近似，无法验证真实 bestAsk / spread。条目要求的 `spread ≤ 0.02` 历史无法逐场核实；本回测的“half-spread > 0.02”计数为 0，只是模型假设，不是观测。
2. **last print 可能陈旧**：主窗口 6 小时、敏感性 24 小时，取窗口内最后一笔；没有建模打印之间的价格漂移，也没有建模大单冲击。
3. **匹配误差**：日期 ±1 天 + 归一化队名，96.6% 匹配；69 个未匹配主要是改期（如 Everton–Liverpool 改到 2025-02）和 2026/27 新升班马/队名差异。未匹配样本没有进入结果。
4. **分联赛样本小**：I1 只有 17 场匹配、4 次触发；F1 7 次触发。分联赛结论不可靠，主结论以 ALL 为准。
5. **基准率模型**：B365 收盘赔率去水后的 qD 分桶，桶内历史频率；不同赛季的联赛平局率会漂移，expanding window 仍可能滞后。小样本桶回退到五联赛合并，可能混入联赛差异。
6. **成交数据上限**：data-api 每个市场大约只能取最近 2 万笔；本回测按 newest-first 取到 `T−24h`，热门市场若在窗口内有超过上限的成交，可能截断。
7. **费用/规则变动**：费率按 0.05、按 GUIDE §8 的 taker 公式；未来费率或结算规则变化未建模。取消/改期按 Polymarket 结算，未单独做规则套利。
8. **口径**：P&L 与 Brier 用 football-data `FTR` 作为结果记录；本样本 Polymarket 结算与 FTR 100% 一致，所以没有剔除。若未来出现不一致，需单独处理。
9. 没做年化、资金曲线、最大回撤、仓位上限；独立结果按比赛计，一场 1 份。
