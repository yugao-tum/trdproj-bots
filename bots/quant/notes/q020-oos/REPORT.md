# quant-020 可成交价时间切分样本外回测

**结论：HOLDOUT 按条目冻结的失败标准判 PASS**（带内 47 个事件，净 PnL/份中位 +0.4376，YES 率 0.5745 > 平均入场价 0.4881）。但这不是稳健的边：DISCOVERY 同口径中位 −0.4313、均值 −0.0494，POOLED 均值仅 +0.0081/份，bootstrap 95% CI 均跨 0。且任一历史 14 天窗口的带内事件最多 **24** 个，未达到条目「两周 ≥30」的检验门槛。全部数字由 `q020_oos.py` 生成，stdout 见 `run_output.txt`，逐事件表见 `events.csv`。

## 2. 预先写死的方法（脚本头部，先于结果）

- **时间切分**：按 `endDate` 排序，最早 60% = DISCOVERY，最新 40% = HOLDOUT。切分点 `2026-05-05T13:00:00Z`；DISCOVERY 830 个、HOLDOUT 554 个事件。
- **规则冻结**：`0.40 ≤ p_24h ≤ 0.55`，吃单买 YES；不重新拟合区间。
- **可成交价**：`p_24h` = data-api 中时间在 `[endDate−72h, endDate−24h]` 的最后一笔 YES 成交（NO 成交按 1−price 换算）；入场 ask = `p_24h + 0.01`（预声明 1¢ 半价差）。无成交 = unpriced。
- **费用**：GUIDE §8 公式，费率按条目实取的 **0.05**：每份费 = `0.05 × ask × (1−ask)`；净 PnL/份 = 兑付(1/0) − ask − 费。
- **敏感口径**：`p_6h` = `[endDate−54h, endDate−6h]` 最后一笔，ask = `p_6h + 0.01`。
- **独立性与不确定性**：一 Gamma 事件 = 一公司-季度 = 一结果；按 `endDate` 的 ISO 周做 block bootstrap（周聚类有放回，10000 次，固定种子 20261020）。
- **旧价格源对比**：对同一批可成交价带内事件，取 CLOB `prices-history` 中 `t ≤ endDate−24h` 的最后价格，同样 +1¢、同费率，算旧口径净 PnL。

## 4. HOLDOUT 判定

条目冻结的失败标准：带内按事件净 PnL 中位 ≤0，或带内 YES 率 ≤ 平均事前价。本次 HOLDOUT：

- 中位净 PnL/份 **+0.4376 > 0**；
- YES 率 **0.5745 > 平均入场价 0.4881**（也 > 平均 p24 0.4781）；
- 带内事件 **47 ≥ 30**。

→ **PASS**。但脚本的 bootstrap 95% CI 为 **[−0.1074, +0.1841]**，跨 0；DISCOVERY 中位为负；POOLED 均值 +0.0081/份、每 $ 投入 +1.66%。因此这是「按冻结判据 PASS、统计上不显著」。

## 5. 对门槛 5 / 6 的含义

- **门槛 5（扣成本后够用）：按冻结判据 PASS，但证据弱，不能视为已证实。** HOLDOUT 中位为正、YES 率高于入场价；但均值 CI 跨 0，DISCOVERY 为负，POOLED 均值约等于 0。年化数字（HOLDOUT +4434.67%）来自 1.25 天的极短占用期，是算术放大，不应作为可持续收益的证据。
- **门槛 6（两周内能检验）：不满足。** 全部历史里带内事件只占 7.65%；任一滚动 14 天窗口带内最多 **24** 个，低于条目要求的 30 个独立结果。按历史密度，两周窗口通常远少于 30 个；本回测的 101 个带内事件是跨 2025-06-05 至 2026-10-20 累积的，不是两周可完成的检验。

## 6. 限制

- **成交打印 ≠ 可成交盘口**：data-api 是逐笔成交价，不是卖一价/深度；1¢ 半价差是预声明假设，真实价差可能更宽。无法从历史 L2 复核。
- **价格时点**：`p_24h` 取窗口内最后一笔成交，可能距 `endDate−24h` 有数小时；敏感口径 `p_6h` 仅作稳健性检查。
- **结算口径**：结果取 Polymarket `outcomePrices`；结算源 SeekingAlpha 付费墙，未独立核对 strike 与公布 EPS，也未区分 96h/45 天兜底判 NO 的事件。
- **时间切分**：按 endDate 前后切分不是随机抽样；DISCOVERY/HOLDOUT 的财报季构成与市场环境不同。HOLDOUT 起点 2026-05-05，覆盖 5 月至 10 月。
- **资金占用**：用 `endDate` 作为 resolution 代理，实际 UMA 结算到账可能再晚数小时至 2 天，年化会被高估或低估。
- **重复事件**：仅合并了同一公司同一 endDate 的 EFX GAAP/非 GAAP 一对；不同日期但同一财报的电话会/修订未再合并。
- **data-api 保留量**：端点只保留最近约 2 万笔/市场，offset 上限 10000；本次 0 个市场截断，但更早或更活跃市场可能缺成交。
