# Frozen diagnostics before ledger outcomes
Frozen 2026-10-20 10:28 UTC. Event unit is a maximal continuous gate-on run in the 01 signal, truncated only at study boundaries, never at calendar-year boundaries. On exit day the old inventory's overnight P&L and exit costs belong to that same preceding event; gate-off idle days are not events. A gate-on run with zero exposure is still a gate segment, not necessarily an economic position episode. All four scenario rows share one event ID; neither symbols, fees, capital allocation nor calendar months multiply evidence. Shared UTC months are market-time clusters only and can intersect events, not independent observations.
Top 10 positive daily P&L share is numerator top ten positive daily changes / sum all positive daily changes. Top one/three profitable event share has denominator sum positive event P&L, and net-P&L contribution is separately labeled. Removing best event is additive realized P&L attribution, not a self-financing replay and not a strategy candidate. Exact calendar years and complete period are fixed reporting windows, never filters for selection. Daily total-account return correlations with all fixed same-budget benchmarks are descriptive, with no automatic independent-leg or 3% qualification conclusion.
Failure gates: any cash reconciliation or event attribution mismatch blocks economic conclusions; any missing daily coverage blocks completed classification; observed venue cap breach disqualifies that implementation; high-only upper bound breach is uncertified, not observed breach; no actual-fill evidence and no dependence proof mean conditional simulation and no independent-event qualification. Concentration and best-event removal are fragility diagnostics without invented ex-post pass thresholds. Minimum evidence is a predeclared prospective non-overlapping validation period with independently observed synchronized executable prices, depth/costs and dynamic-cap evidence, plus dependence-aware uncertainty and recognized-rule review.
