# 固定连续VM执行补证与停止决定

## 决定

停止这次事前固定的连续账户 B / VM_BTC_SMA50 next-open 规则，包括原 2500 场内配置和唯一事前固定的 1250 buffer 配置。不是停止所有波动管理机制，也不是宣布 quant-001 原样本结果虚假。连续相位、窗口、执行时点和资本口径与原研究有差别；保留其原成果、r16 冻结成果和所有指导文件。

不再换初始金额、费用、SMA、五日相位、样本窗或闸门去救活这一次规则。当前低费收益已不足 3% 必要收益条件，没必要先追加真实成交验证来拯救它；更不能将低费的正总收益写成达标年化。

## 四道证据门

1. 收益：四组均未达到约 8% 主目标；均不足 >3% 低相关腿的必要收益条件。低相关腿不是仅过收益即合格，不能省略相关性与规则审查。
2. 动态资本：原配置观察参考价已失败；buffer 仅在冻结历史、零在途与当前条件模拟下获得保守界认证，不是未来保证。
3. 执行：真实历史 open 是当日日内第一笔成交参考，不是本账户保证成交；三币同步、可成交深度、价差及冲击未验证。终端清算费用完整纳入并不补齐这些未知。
4. 独立结果：34 个唯一 gate-on 段只有 23 段实际持仓，11 段零损益；33 个共同月份也不能变成独立结果。四场景、三币、费用变体均不得重复计数。未证两周内至少 30 个独立结果，也未证事件统计独立。

最优的末段（2026-08-18 至 09-30，含预定终端费用）占低费全窗净利 190.09%；前三盈利段占正事件利润 73.86% / 74.93%。删除最佳段的加法损益归因四组都负，但这只是集中度诊断，不是可自融资反事实重跑，也没有事后发明集中度达标阈值。与同配置 BTC 日账户回报相关 0.4896–0.4965，EW 为 0.5363–0.5445；现金相关未定义，不填零。

- 条件模拟：本轮全部策略及 12 个预算基准，非真实成交。信号 1253 次截断和 6 次未来扰动检查未发现因果变化；这是测试范围内的结论。
- 真实成交：没有，也不授权进行。
- 官方达标/得分：没有；不得预记分。
