# dot-032：聚合分数可给严格瞬时界，但仍不能证明日奖励或盈利

结论：在已知完整且合资格的竞争侧分数 A、B、固定调整中价、c=3 的条件下，maker 分组虽不可精确识别，奖励分母仍有可证明的最优松弛界。不是再次重复“L2 没有 maker 身份”，而是把缺口缩小为可验证条件下的区间。dot-032 保持 STOP，不新增机制、PLAN、前向起点、实测结果或待核状态。

## 新的数学结果

调整中价在 [0.10,0.90] 内，竞争分母 D=Σmaker Qmin 满足：

max(A/3, B/3, (A+B)/4) ≤ D ≤ min(A,B)+|A−B|/3。

上下界均在只知道 A、B、允许任意非负 maker 分组的松弛域可达。具体固定订单不可任意拆分时，仍是有效外界，但不一定可达。边界价 0.10、0.90 属于上述区间；外侧只允许双边计分时，0 ≤ D ≤ min(A,B)。

新增反例：A=B=100 时最低可以是50，而非旧例的66⅔。两名 maker 持 (75,25)、(25,75) 即可；同一 maker 持 (100,100) 则为100。该例也可用每侧75、25两笔固定合资格分数实现：权重1/4、股数300与100、最低奖励股数100。

“竞争订单合并为一个 maker”无统一保守方向。A=B=100 时其分母100可高估；A=300、B=100时其分母100可低估，因为 (100,100)+(200,0) 的实际分母为166⅔。因此不能一概称该近似保守。

## 自有纸面份额与决策意义

自有合资格 Qmin=q>0，A、B必须排除自有订单。严格瞬时份额为：

q/(q+上界) ≤ 份额 ≤ q/(q+下界)。

合成例：竞争 A=B=100，自有分数(30,30)时 q=30，份额在23.08%至37.50%；自有(30,0)时 q=10，份额在9.09%至16.67%。两种报价不是等资本/等风险比较，不是报价建议。若中价在外侧，单边自有订单 q=0。

要对所有松弛分组保证瞬时份额至少h，需要 q≥h×上界/(1−h)。这是有条件的数学筛选，不是日收益预测。maker ID并非任何“瞬时保守区间”都不可缺少；但精确分母、实际资格、覆盖与时间仍未识别。

## 不能跳过的条件

- A、B是互补两结果的合资格加权分数，不是单一结果的原始买卖量。需完整竞争覆盖、正确调整中价/资格/权重；浅层或漏侧L2没有竞争分母有限上界。
- 原始价位总量100可能是一笔合资格100，也可能是两笔不合资格50，不能由价位总量确定逐订单资格。若原始数据仅能证明分数上界，仍可用单调性得到D上界及自有份额下界，但D下界退为0；须独立证明自有q有效。
- 自有订单若改变调整中价、资格或计分区间，必须用加入后的分数重算，不能直接套加入前盘口。
- 队列优先级不直接进入奖励公式，却影响订单存续、成交与逆向选择。只触价不能当成交，撤单也不是队列成交消耗。
- 官方随机分钟时点与实际存续尚未掌握。仅在所有实际有效样本、正分母和完整人口都已知时，最终份额才是这些瞬时归一化份额的平均，逐样本界才可平均。单张非官方采样快照不提供正的整日奖励下界。
- 当前奖励池、最低1美元支付的聚合口径、费用/库存/退出/资本成本均未闭环；严格瞬时份额下界不等于可支付现金，更不等于净正盈利。发布时序门槛也未改变。
