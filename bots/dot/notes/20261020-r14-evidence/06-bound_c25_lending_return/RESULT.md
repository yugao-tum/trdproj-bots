# C25：固定全年利息的资本上界否决

结论：停止为本固定 Aave V3 Ethereum USDC 标的/年份补现金数据。即使稳定币始终平价、全部可提款、gas 为零，入出各 0.30% 后资金腿回报最多约 2.953280%，低于组合腿 3% 门槛；5000 总资本、单场所最多 2500 的松弛上界只有 1.476640%，低于独立 8% 门槛。这是条件利息模型的否决，不是真实已盈利、不否决其他年份或整个借贷机制，不评记成功改善或新增机制。

## 固定输入和复算

本次 2026-10-20 UTC 仅重读本地冻结记录，没有新增网络请求。原来源为 https://eth.drpc.org 的历史只读 RPC，原采集记录 2026-10-19 UTC；区块 23479243（2025-09-30 23:59:59 UTC）及 26093737（2026-09-30 23:59:59 UTC），恰好 365 天。normalized-income 整数分别为 1146732252730421153570597745、1187714062272872680314062635。来源记录、原始状态及原任务预登记 SHA256 见 source-manifest.json；不是本次新查询，也不是第二节点独立确认。

令 F=末指数/初指数=1.0357379060760452076。B 是包含入场成本的初始现金预算，C=5000；入、出摩擦 ci=co=0.003，链费 G>=0 从闲置现金支出。假定 USDC/USDT 入出均为 1、闲置现金收益 0、scaled 持仓不变：

- 实际存入模型数量 D0=B×(1-ci)，期末毛场所余额 D1=D0×F。
- 期末净出金模型 = D1×(1-co)；净利息模型 P=B×[(1-ci)F(1-co)-1]−G。
- 总资本收益 P/5000；资金腿收益 P/B，不能把后者或指数涨幅冒充前者。
- B=2500、G=0：毛指数利息在无成本模型为 89.344765 USDT；计两边成本后 P=73.832001，腿 2.953280%、总资本 1.476640%。哪怕完全零成本，总资本也只有 1.786895%。
- 更宽松地简单从毛利率扣 0.60 个百分点，腿仍只有 2.973791%，同样不到 3%；结论不靠微小计费口径差异成立。

B=2500 时，D1=2581.576731，超过 2500 的期末场所上限，因此前述只是放松约束后的乐观上界。仅把期末余额压至 2500，最多 B=2421.001059，存入 2413.738056，G=0 的 P=71.498941，总资本仅 1.429979%。这仍未证明全年动态上限合规：没有全年余额/USDT 价格路径。若有中途提款、兑换或再投，属于其他现金规则，不能用这条固定持有模型证明其收益。

链费敏感性：G=0/5/20/50/100 时，B=2500 的 P=73.832001/68.832001/53.832001/23.832001/−26.167999，总资本收益=1.476640%/1.376640%/1.076640%/0.476640%/−0.523360%。这是人为固定压力参数，不是观测链费。零盈亏链费界 73.832001。资本 500/1000/1500/2000/2500 的零链费总资本回报 0.295328%/0.590656%/0.885984%/1.181312%/1.476640%。

腿要达到 3%，毛指数至少 3.620792%；半资本配置若要求总资本 3%/8%，毛指数需至少 6.638873%/16.699145%（仍是松弛资本约束、零 gas）。没有以换币/换年份搜索“赢家”。

## 适用边界及七门槛

1. 机制：满足描述。借款人支付利用率决定的利息给供应人；本次未重新核机制。
2. 免费收益数据：部分满足。已有一整年实际历史指数两个端点，但缺真实账户出入金、全年实施升级、价格、提款能力、完整收益路径。不是完整真实历史策略回测。
3. 小资金：部分/不确定。现金公式遵守不借款；满额预算违反期末 cap，缩减预算仅证明两端，不证明全年动态合规或执行容量。
4. 不重复：不满足“新机制”。明确 supplement → Y-Y1-stable-lending / dot-025。
5. 扣成本收益：不满足。固定条件下腿 <3%，总资本 <8%；低相关性亦未检验。
6. 两周内 30 独立结果：不满足。一个全年区间不是 365 个独立事件；5 个资本/链费参数也不是新样本。
7. 出处：部分满足。冻结链上记录、官方地址簿/接口资料与本地复算可追踪；本次无新增外部读取，RPC 单源、历史实现及真实现金证据不足。

重要：平价条件只限定利息比较。实际 USDC/USDT 上涨或下跌会改变实际回报，故这不是无条件 USDT 收益数学上界；额外价格收益不能归功于利息机制。6 位代币舍入、历史代理升级和账户持仓未复核；这些不能被描述成已实现的现金利润。未盲目再扣 reserve factor。
