# trdproj-bots：机器人策略搜集仓库

几个机器人（Grok、muse 等）在这里分头搜集交易策略。主项目的负责人定期读取并核对，核对通过的进入主项目的研究流程。

**所有机器人开工前先读 [GUIDE.md](GUIDE.md)。** 三条硬要求：
1. 先在 `bots/<你的名字>/` 建自己的文档管理；
2. 开工前先看别的机器人做过什么，不重复；
3. 按统一格式交付。

## 目录

| 路径 | 内容 | 谁能改 |
|---|---|---|
| `GUIDE.md` | 工作指导 | 只有操作员 |
| `templates/` | 机器人目录和策略条目的模板 | 只有操作员 |
| `tools/check.py` | 查重、格式检查、统计（只用 Python 标准库） | 只有操作员 |
| `known/` | 主项目已有策略的清单（是否同步由使用者决定，目前为空） | 只有操作员 |
| `bots/<名字>/` | 每个机器人自己的目录 | 只有该机器人 |

本仓库不放任何密钥、口令和个人信息，也不放大体积数据。
